## Baziq Calculator 1.1.3

The first public release of Baziq Calculator, by Baziq Hue: a calculator and currency converter for Android. It includes the changes prepared for 1.1.2, which was not published.

### Currency converter
- **Typing a new amount.** Tap a currency showing zero and type 9: you get 9, not 0.9. Decimals such as 9.5 or .5 work as before.
- **Editing an amount.** You can move the cursor inside an amount and change a digit.
- **Base currency remembered.** The converter reopens with the base currency you last used. With the automatic local currency turned on, it still switches when you arrive in another country.
- **Rates shown in full.** Exchange rates keep the precision of their source (1 USD = 129.84 KES, not 130).

### Calculator
- After deleting back to an operator, the next digit is spaced correctly ("7 + 3", previously shown as "7 +3").
- The keypress timing code used during development no longer runs on every key.

### Settings
- **Backup & Restore:** export your history, currency list, custom rates and settings to a file, and import it on another phone. Choosing a very large file by mistake is now rejected without reading it all into memory.
- The decimal-precision buttons no longer break their labels on narrow screens.
- The offline rate table states its real number of currencies.

### Install
Download `baziq-calculator.apk` below, open it on your phone and allow your browser to install apps if Android asks. Android 8.0 or later. The app is distributed here, not on Google Play.

Every official release is signed with the same Baziq Calculator release key, so later versions install over this one and keep your data.
