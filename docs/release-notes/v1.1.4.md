## Baziq Calculator 1.1.4

### Calculator
- **Scientific functions work with =.** Pressing √ 1 4 4 = now gives 12. Previously the functions (√, sin, cos, tan, ln, log, 1/x) left a bracket open and = reported "Mismatched parentheses" unless you closed it with the ( ) key. Open brackets are now closed for you, and the live result appears while you type.

### Install
Download `baziq-calculator.apk` below and open it on your phone; allow your browser to install apps if Android asks. Android 8.0 or later. It installs over 1.1.3 and keeps your history, currencies and settings.

Every official release is signed with the same Baziq Calculator release key.
